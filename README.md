# 📊 E-commerce Sales Analytics Dashboard

## 🚀 Project Overview
This project showcases an end-to-end Power BI dashboard built using an e-commerce dataset. It focuses on analyzing sales, customer behavior, delivery performance, payments, and customer sentiment.

---

## 🛠️ Tools Used
- Power BI  
- SQL (Data extraction & transformation)  
- DAX (Measures & KPIs)

---

## 📌 Key Features
- Interactive multi-page dashboard  
- KPI tracking (Revenue, Orders, AOV, Ratings)  
- Sales trend and YoY analysis  
- Customer segmentation (new vs returning)  
- Delivery performance insights  
- Payment behavior analysis  
- Customer sentiment intelligence

## 💡 Key Insights
- Revenue shows consistent growth with seasonal trends  
- Majority of customers prefer credit card payments  
- Delivery delays negatively impact customer ratings  
- Certain product categories show lower customer satisfaction  
- High installment usage indicates affordability-driven purchases
